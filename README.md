## 🧩 주요 기능 및 메뉴 설명

### 1. 교차로 교통량
- 시흥시 교차로별 교통량 정보 지도 시각화
- 시간에 따른 교통량 변화 확인 (재생, 멈춤 기능 포함)
- 교차로별 음영유형 레이어 제공 및 클릭 시 세부 정보 표출
- 표출 정보: 도로명 / 차로위치 / 교통량 / 속도 / 대기행렬(m) / 이동방향

### 2. 대기행렬 길이
- 차로별 차량 대기 정보를 시각적으로 표현
- 화살표로 진행 방향 표시, 마우스 오버 시 세부 정보 표출
- 표출 정보 : 도로명 / 차로위치 / 대기행렬(m)

### 3. 링크-속도
- 차로(통합/개별)에 따라 음영유형 레이어 다르게 표출
- 줌레벨(17.5)을 기준으로 차로 통합/개별 전환
- 레이어 클릭 시 속도 기반의 상세 정보 표출
- 표출 정보 : 도로명 / 차로위치 / 음영유형(1~6) / 내용 / 속도 / 돌발정보
※내용 : 기기고장, 날씨문제 등 음영유형에 해당하는 내용

### 4. 링크-교통량
- 링크-속도와 기능 동일, 단 교통량 정보 중심으로 표출
- 표출 정보 : 도로명 / 차로위치 / 음영유형(1~6) / 내용 / 속도 / 돌발정보
※내용 : 기기고장, 날씨문제 등 음영유형에 해당하는 내용

### 5. 음영구간
- 차로(통합/개별)에 따라 차로 및 교차로 레이어 표시
- 수집 장치 정보 포함 (VDS, CCTV, LiDAR, 스마트교차로 검지기)
- 클릭 시 장치별 상세 정보 표출.
- 단, 교차로는 레이어만 제공. 상세 정보는 차로만 제공.
- 표출 정보(공통) : 도로명 / 차로위치 / 음영유형 / 내용 / 장치명 / 장치ID
- 장치 정보(VDS) : 속도 / 교통량 / 점유 시간 / 대기행렬
- 장치 정보(CCTV) : 속도
- 장치 정보(LIDAR) : 속도 / inout
- 장치 정보(스마트교차로 검지기) : 속도 / 교통량 / 대기행렬
